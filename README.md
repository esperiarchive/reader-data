# The Esperia Archive — Reader Data

Story text, translations, character information, documents and mail for **The Esperia Archive**.

Images and voices are in [afkjourney-media](https://github.com/esperiarchive/afkjourney-media).

## Using the files
The reader's `data_base` uses this URL, with `<commit>` replaced by a full Git commit ID:
```text
https://raw.githubusercontent.com/esperiarchive/reader-data/<commit>/data/
```
To check a downloaded copy, run `python tools/verify_data.py`.

Game text and other original content belong to their respective owners.
